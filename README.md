# Dotfiles

![](https://github.com/vaclav-seidl/dotfiles/blob/main/screenshots/Screenshot%20from%202026-05-16%2000-32-04.png)

## Configuration

Use GNU Stow to link dotfiles

## Included tools

- bash profile
- kitty
- niri
- rofi
- wayle
- fish

## Includes scripts

- aliases
- usb guard (sounds alarm when an USB device gets unplugged)
- woomer (freeze screen on the active display)
